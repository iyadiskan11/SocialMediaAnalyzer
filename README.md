# PROJECT DESIGN ANALYSIS AND DESIGN

VIBE FEST 2026 is a youth lifestyle and technology 
festival that involves gaming, music, content 
creation, food, and artificial intelligence. 
As the event grows, the organisers face challenges 
in route planning, keyword searching, and travel 
optimisation. This project applies Design Analysis 
and Algorithm concepts to solve these problems 
using Java. The project consists of three tasks: 
VIBE Hunt Challenge, which finds a valid route 
through all activity zones; VIBE Trend Scanner, 
which compares Naïve String Matching and 
Rabin–Karp algorithms to search visitor feedback; 
and VIBE Creator Road Trip, which uses an 
approximation technique to generate a suitable 
campus travel route. Through implementation and 
complexity analysis, this project evaluates the 
efficiency and limitations of the selected 
algorithms.
